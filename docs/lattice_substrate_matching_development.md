# 固溶体候选评价：晶格常数匹配与衬底主应变开发任务书

版本：1.1；日期：2026-11-03。

**使用方式：把本文件交给负责开发的 AI，作为需求、实现和验收依据。本文可在其他开发环境独立使用，不依赖编写者的目录、历史会话、项目日志或试验文件。**

## 1. 你需要完成什么

在现有固溶体筛选软件输出候选材料后，新增两个功能：

1. **晶格常数匹配**：评价一个固溶体系的两个端元，在统一晶胞和晶轴对应关系后的晶格失配。
2. **衬底匹配及主应变评价**：对每个最终候选体系在指定中间组分下的一个弛豫合金 SQS，默认 seed101，搜索合适的衬底、晶面和二维超胞，计算面内主应变并推荐方案。

最终生成一个候选评价表，汇总已有带隙、声子、混合焓、凸包上能，以及本次新增的两项几何指标。每项结果需要有数值、单位、有效性状态、来源和推荐理由。

**本次真正新增计算的是两项几何功能。带隙、声子、混合焓和凸包上能从已有结果读取，不在本次任务中重新开发这些计算流程。**

衬底匹配只对最终合金组分计算，不对端元做衬底匹配。端元 A/B 仅用于第一项晶格常数比较。若一个体系有多个组分，按“体系＋实际组分”分别评价。

衬底只计算一个构型，是控制计算量的代表构型筛选策略，不等同于验证构型间稳健性。seed202 等既有带隙、声子、混合焓和凸包结果继续保留，不随衬底选择一起丢弃。

seed101 是统一选择约定，不表示它天然具有最低能量、最佳 SQS 质量或最优衬底匹配。

开发 AI 应先检查接收方现有项目结构和输入数据，编写适配层，再实现功能。不要假设接收环境存在某个特定服务器路径或历史文件；下面所有文件名、模块名和命令均是建议接口，可按实际项目组织调整，但科学定义和输出含义必须保留。

## 2. 必须采用的候选评价表

最终软件的说明文档和评价页面/报告中，必须包含下表：

| 项目 | 优先候选条件 | 中间区间或待核验条件 |
|---|---|---|
| 合金带隙 | 两个有效构型均落入目标区间 | 构型结果跨越目标边界，或只有探索性计算 |
| **晶格常数匹配（新增）** | **统一晶胞和晶轴对应关系后，最大晶格长度失配≤3%，且晶胞角度检查通过** | **3%–5% 可作备选；>5% 标记较大失配风险；无法建立可靠晶胞对应关系时标为“待核验”** |
| 声子 | 无低于 −0.1 THz 的显著虚频，且计算质检通过 | 临界软模、未收敛或采样不足时需复核 |
| 混合焓 | ≤25 meV/atom | 25–50 meV/atom；>50 降低优先级 |
| 凸包上能 | ≤25 meV/atom | 25–100 meV/atom；>100 降低优先级 |
| 衬底主应变 | 选定代表 SQS 存在最大绝对面内主工程应变≤1%的匹配方案 | 1%–3% 可作备选；搜索范围内无解标为“未找到”；代表构型缺失或无效时标为“待补充” |

| 评价维度 | 使用的指标 | 支持什么结论 |
|---|---|---|
| 光谱适配 | 最终合金带隙、目标探测波段 | 具有进入目标光谱范围的带隙基础 |
| 材料稳定性 | 晶格匹配、声子、混合焓、凸包上能 | 在所用方法和阈值下值得继续研究 |
| 薄膜集成 | 固溶体的衬底匹配、主应变、面积 | 存在低应变外延几何候选方案 |


- 带隙目标区间必须由配置指定；未指定时显示“目标区间未设置”，不擅自填一个范围。
- 晶胞角度检查第一版暂设最大对应角差≤1°，保留为可配置参数。
- 上述数值是初始筛选设置，需要保留修改入口；它们不是普适的固溶或外延成功判据。
- 带隙等已有性质中“两个构型”仍指同一实际组分的两个有效合金构型；其预期覆盖按原规则保留。衬底模块只要求选中的一个代表构型有效，不再要求跨构型共同方案。
- 晶格失配较大是辅助风险，不能单独推翻已经验证的合金稳定性结论。搜索范围内未找到衬底，也不能写成“材料无法外延”。
- 软件可以输出：该候选体系在带隙适配、结构稳定性及衬底几何匹配方面具备进一步研究的依据，建议优先开展面向目标波段的光电探测验证。

## 4. 输入数据怎么准备

### 4.1 建议输入目录

```text
input/
  candidates.csv          # 候选体系、实际组分、预期构型集合
  endmembers.csv          # 两端元结构及参考方法
  alloy_structures.csv    # 最终弛豫合金结构及构型身份
  properties.csv          # 已有带隙、声子、混合焓、凸包结果
  substrates.json         # 衬底晶相及结构清单
  structures/             # 结构文件，也可引用外部只读文件
config.json               # 阈值、搜索范围和执行设置
```

这些是交换格式建议。若原软件已有等价文件，编写适配器读取，避免要求用户重新手工整理大量数据。所有路径来自参数或配置，相对路径以所在清单文件的目录为基准。

### 4.2 必要身份和字段

| 输入 | 至少需要的信息 |
|---|---|
| 候选体系 | `candidate_id`、`pair_id`、端元 A/B 身份与组成、实际组分 x、已有性质的预期 `structure_id` 集合、所用端元参考版本、衬底代表构型选择规则 |
| 端元结构 | `pair_id`、A/B 角色、`reference_set_id`、结构 ID、结构文件、SHA-256、计算方法、弛豫状态 |
| 合金结构 | `candidate_id`、`structure_id`、构型标签/seed、实际组成、实际替换位比例、结构文件/SHA、计算方法、弛豫/QC 状态、母相和超胞变换信息 |
| 已有性质 | `structure_id`、性质数值与单位、对应结构 SHA、方法、状态、QC、来源；声子/能量参照等原有告警也要保留 |
| 衬底库 | `substrate_id`、化学式、晶相、结构文件/SHA、来源/方法；可选允许的晶面列表 |

Stage 13 GUI会在调用几何CLI时同时传入当前Stage 12推荐表。CLI仅按候选pair index、实际组分和structure ID精确关联性质，再用合金结构清单中的SHA绑定结构身份。推荐表中的端元带隙不会当作合金带隙。`properties.csv`接受`property,value,unit`长格式及兼容宽格式。

同一个 `pair_id` 可有多个实际组分，用不同 `candidate_id` 区分。预期构型数量由输入清单规定，不能从成功计算的行数推断。

组分 x 表示约定替换子晶格上 B 组分的占比；同时保存替换原子数与可替换位点数，用于核验实际比例。它不一定等于 B 元素占整个晶胞的原子分数。

原数据若存在重新编号，先建立明确的原索引映射。重复身份、结构 SHA 不一致、同一身份对应不同组成或方法版本，都应报错或进入明确的待核验状态，不能静默覆盖。

### 4.3 输入质量要求

- 晶格匹配优先使用相同方法、相容弛豫设置及参考状态的两个端元。多个参考版本并存时显式选择 `reference_set_id`。
- 合金衬底匹配默认使用全晶胞弛豫完成且 QC 通过的最终合金结构。固定晶胞结果如被允许，必须标为受约束结构。
- 合金和衬底可以来自不同方法，但需要记录双方来源和差异；例如 MLP 弛豫合金配 MP DFT 衬底属于几何预筛。
- 带隙必须属于被评价的合金构型，不能把端元带隙、未收敛结果或未经验证的小胞结果直接填成已验证合金带隙。
- 不能把混合焓、形成能和凸包上能互相改名。输入数值使用各自正确参照和单位。

缺少某项已有性质时，仍可以完成几何功能，主表对应单元格留空并注明缺失。几何模块不得自动启动新的昂贵计算来补数据。

## 5. 功能一：晶格常数匹配怎么实现

### 5.1 建立真实晶胞对应关系

按以下顺序实现：

1. 读取同一材料对的两个端元，核验结构身份和方法。
2. 保留固定元素身份，仅将允许替换的元素/位点建立对应；不要允许所有元素任意交换来凑匹配。
3. 统一原胞/常规胞约定，找到可靠的晶轴及位点映射；允许合法换基、轴置换和可追溯的超胞表示差异。
4. 保存从输入晶胞到比较晶胞的变换矩阵、位点映射、原点平移和映射残差。
5. 在对应的真实晶格上计算长度、角度、体积及完整形变。

不得直接按 a、b、c 的大小排序后认为它们相互对应。也不能让一个端元用原胞、另一个用大超胞直接比较长度。比较晶胞必须代表相同计量大小，不能用任意高阶超胞匹配掩盖端元本身的尺寸差异。

`StructureMatcher` 默认可将两结构缩放到相同体积。即使为了寻找拓扑对应使用了缩放副本，最终失配也必须回到原始真实尺寸计算；保存的映射必须能够重建原晶格。[官方说明](https://pymatgen.org/pymatgen.core.html#pymatgen.core.structure_matcher.StructureMatcher)

映射搜索容差应宽于最终评价阈值，并单独记录。无法找到可靠映射时输出“待核验”，不能输出零失配或直接判不合格。多个非等价映射给出不同分级时保留歧义，不能只挑最好结果。

### 5.2 晶格失配定义

对于已经建立对应关系的长度：

\[
\delta_l=\frac{2|l_A-l_B|}{l_A+l_B},\quad l\in\{a,b,c\}
\]

\[
\delta_{\mathrm{lattice}}=\max(\delta_a,\delta_b,\delta_c)
\]

对应角差定义为：

\[
\Delta\theta_{\max}=\max(|\alpha_A-\alpha_B|,|\beta_A-\beta_B|,|\gamma_A-\gamma_B|).
\]

内部失配使用小数：0.03 表示 3%。例如 5.00 Å 与 5.10 Å 的失配为 1.98019802%。这个定义交换 A/B 后不变。

### 5.3 非正交晶胞要核验完整形变

晶格基矢按行存储为 `L_A,L_B`，A→B 形变梯度满足：

\[
F_{AB}=(L_A^{-1}L_B)^T,\qquad F_{AB}L_A^T=L_B^T.
\]

使用线性方程求解；对 F 做 SVD，得到主伸长比 λ。保存方向性的工程应变 λ−1，另计算对称诊断量：

\[
\delta_{\mathrm{principal,sym}}=\max_i\frac{2|\lambda_i-1|}{\lambda_i+1}.
\]

后者包含剪切效应，不替代 a/b/c 长度失配。若它与长度指标在 3%/5% 分档上产生不同结论，应进入“形变待复核”。刚体旋转不得产生虚假的应变；所有晶胞统一右手约定。

### 5.4 晶格结果状态

- **优先**：映射和来源有效，最大长度失配≤3%，最大角差≤1°，完整形变无冲突。
- **备选**：核验有效，3%<最大长度失配≤5%，角度检查通过。
- **较大失配风险**：可靠映射下最大长度失配>5%，保留具体数值。
- **待核验**：映射缺失/歧义、角差>1°、完整形变冲突或参考方法不兼容。
- **计算失败/数据缺失**：保留原因，数值为空。

存在角度、映射或形变冲突时，“待核验”优先于自动给出优先/备选分档。较大失配作为辅助风险保留，不单独删除候选。

## 6. 功能二：衬底匹配和主应变怎么实现

### 6.1 薄膜模型与衬底库

薄膜使用最终弛豫的完整周期 SQS，记录 `film_lattice_model=relaxed_sqs`。不要强制对称化随机合金，不使用端元晶格插值替代实际合金。

衬底使用指定晶相的标准胞，保留原结构、标准化变换和容差。衬底库由用户配置；可从 Si、Ge、Al2O3、MgO、SrTiO3、MgAl2O4、GaAs、GaN、AlN、SiC、ZnO、LaAlO3 等材料中选择，但必须明确晶相，不能只按化学式拿任意一条结构。

几何模块默认读取本地衬底清单。若增加 MP 下载功能，作为独立数据准备步骤，保存 material ID、结构版本、来源和校验和；不在匹配循环中隐式联网。

### 6.2 搜索流程

1. 枚举薄膜与衬底晶面，第一版默认 `|h|,|k|,|l|≤1`，排除全零和非互素重复。
2. 薄膜 SQS 默认只合并 ±法向；最大指数 1 时有 13 个几何晶面。衬底可按真实对称性去重。
3. 提取二维面内基矢并约化，记录它们在原三维晶格中的整数表示。
4. 用 `ZSLGenerator` 搜索有限面积内的整数超胞匹配，采用 `lowest=False`。
5. 对每个有效解独立计算面积、完整面内形变和主应变。
6. 保留不同选择策略的代表解，按构型及候选体系汇总。

晶面 hkl 必须注明所属晶胞。±法向合并仅用于几何，不代表极性表面的化学终止相同。

建议初始搜索设置：

| 参数 | 初始值 | 含义 |
|---|---|---|
| 最大 Miller 分量 | 1 | 双方低指数晶面 |
| 最大匹配面积 | 800 Å² | 大胞 SQS 的初始搜索范围；必须可调 |
| ZSL 长度容差 | 0.03 | 两个基矢的相对长度容差 |
| ZSL 夹角容差 | 0.01 | 相对夹角容差，不是 0.01° |
| ZSL 面积比例容差 | 0.09 | 候选超胞面积比例搜索参数 |
| `bidirectional` | false | 固定薄膜→衬底口径 |
| 衬底对称识别 `symprec` | 0.01 Å | 保存进元数据 |
| 优先主应变上限 | 0.01 | 1% |
| 备选主应变上限 | 0.03 | 3% |
| 每个候选展示的不同衬底数 | 3 | 推荐数最多为三种不同衬底；较小配置值可减少数量 |

显式检查双方未应变匹配面积均严格小于面积上限。800 Å² 不是物理通用界限，应允许用 400/800 Å² 等范围对照。搜索长度容差 3% 不意味着主应变一定≤3%，必须再计算主应变。

### 6.3 面内主应变定义

对一套匹配方案，薄膜与衬底超胞基矢分别记为 `V_f,V_s`，均为 2×3 行基矩阵。

分别建立右手正交面内坐标：第一轴沿第一基矢，法向为两基矢叉积的单位向量，第二轴为法向叉乘第一轴。将基矢投影后得到 2×2 行基矩阵 `B_f,B_s`。

薄膜→衬底的面内形变梯度：

\[
F_{2D}=(B_f^{-1}B_s)^T,\qquad F_{2D}B_f^T=B_s^T.
\]

对 F 做 SVD，得到主伸长比 λ₁、λ₂：

\[
\varepsilon_i=\lambda_i-1,\qquad
\varepsilon_{\max}=\max(|\varepsilon_1|,|\varepsilon_2|).
\]

输出两个有符号主应变和最大绝对值，拉伸为正、压缩为负。按最大绝对值分档：≤1% 优先，1%–3% 备选，>3% 标为较高应变。

独立核验使用 `G_f=V_f V_f^T`、`G_s=V_s V_s^T` 的广义特征值问题 `G_s u=λ² G_f u`，可通过 NumPy Cholesky 变换实现。

不能用两个晶格长度差代替主应变，也不能把 Green–Lagrange 应变 `(λ²−1)/2` 或 von Mises 应变直接写成这里的工程主应变。

这是合金贴合固定衬底的几何假设，不计算真实的两侧弹性分担和法向松弛。没有合金弹性张量时，弹性能留空并写明“未计算”，不得填零。

### 6.4 保存自洽的匹配方案

每个构型、衬底和双方晶面组合，至少保存以下代表：

1. 最小面积方案。
2. 最小主应变方案。
3. 满足主应变≤1%时的最小面积方案。
4. 满足主应变≤3%时的最小面积方案。

不存在的策略结果留空。每套真实几何解分配唯一 `match_id`，绑定其双方整数超胞矩阵、基矢、面积、形变和应变。

**禁止把一套解的最小面积与另一套解的最低应变拼成同一个推荐。** 推荐主表所引用的解必须能完整回查。

### 6.5 代表构型选择与单构型推荐

1. 对每个 `candidate_id + 实际组分 + 指定参考版本`，先按配置选择代表构型，再运行衬底搜索。默认 `representative_seed=101`，不能先搜索所有种子后挑结果最好的种子。
2. 选择必须核对输入清单的 seed/构型标签、真实结构 ID、实际组成和 SHA；不能仅凭文件名包含 101 判断。若生成器内部随机种子与批次构型标签不同，分别记录并建立明确映射。
3. 要求所选构型的最终弛豫收敛、QC 通过、晶胞有效。缺失返回 `representative_missing`，无效返回 `representative_invalid`，同一条件对应多个未指定版本返回 `representative_ambiguous`。数值为空，不自动换 seed202。
4. 用户可显式配置其他 seed，或按候选指定唯一 `structure_id`；记录覆盖规则和实际选择。显式 ID 优先于默认 seed，但依然必须验证组分、参考版本和结构质量。
5. 只对这一构型搜索；有≤1%解时选择该阈值内最小面积解，有≤3%解但无≤1%解时选择≤3%范围内最小面积解。其余分别报告较高应变或有限范围无解。
6. 每个薄膜—衬底组合选择最大绝对面内主应变最小的匹配方案；再按该最小应变从小到大排序，输出最多前三种不同衬底。面积和应变来自同一个 `match_id`，匹配面积只作应变相同时的次级排序条件。

输出 `selected_seed`、`selected_structure_id`、`selected_structure_sha256`、`selection_reason`、`selection_status`、`available_configurations` 和 `substrate_configurations_evaluated`。后一字段正常为 1，报告范围固定为 `single_representative_configuration`。

报告可写“可用构型 2 个，衬底评价 1 个（seed101）”，不能写“双构型均通过”。也不能因为 seed202 未计算衬底而把已完成的单构型任务标成失败。已有性质若仍要求两个构型，覆盖不足则只影响该性质或综合证据完整度。

### 6.6 搜索无解和 SQS 面积的解释

分别记录“有匹配”“范围内未找到”“表面原胞已超面积上限”“计算失败”和“代表构型缺失/无效/歧义”。不能用一个空表把这些情况混在一起。

最小匹配面积只相对于当前晶胞、晶面范围和容差。SQS 化学周期会放大表面胞；不同大小 SQS 的原始面积不直接用于材料间总排名。

如以后增加平均母相晶格模式，应作为独立模型验证并单独出表，不能无说明替换第一版的实际 SQS 结果。

```text

  substrate_top_matches.csv     # 每个候选推荐的前 N 个不同衬底
```

主表至少包含以下内容：

| 字段组 | 展示内容 |
|---|---|
| 候选身份 | 体系、组分 x、端元身份、实际合金组成、已有性质覆盖、衬底所选 seed/结构 ID |

完整明细至少保存结构 SHA、模型/方法、晶胞约定、整数变换、基矢、面积、F、两个有符号主应变、搜索范围及结果状态。JSON 中缺失值用 `null`，CSV 中留空。

如果现有软件有结果页面，应新增“晶格匹配”和“衬底推荐”列，并允许展开查看明细；如果没有页面，CLI、CSV 和 Markdown 报告即可构成完整交付，不强制另建 Web 平台。

### 7.3 推荐如何生成

保留原有材料推荐等级，单独增加几何评价：

- **几何优先**：端元晶格为优先，所选代表 SQS 衬底为优先，结构和映射证据齐备；注明单构型范围。
- **几何备选**：两项均有效且属于优先/备选，至少一项为备选。
- **几何需复核**：较大晶格失配、角度/形变问题、较高衬底应变，或指定范围未找到匹配。
- **几何数据待补充**：输入缺失、代表构型无效/歧义、计算失败或端元晶胞映射未建立。

若生成六指标综合推荐，规则必须透明：只有全部关键数据有效且满足第 2 节优先条件时，才标为“优先进一步验证”；存在缺失时标“待补充”；中间区间标“备选/需复核”；原有可靠不利证据继续保留。几何匹配好不能自动提升原先因声子或能量问题而暂缓的材料。

不采用六项等权总分，不把晶格失配和衬底应变当作同一个稳定性指标重复计分。最终文字不得声称材料已被证明可合成或能够成功外延。

## 9. 必须通过哪些验收

### 9.1 晶格功能

- 相同晶胞、刚体旋转和合法晶轴置换，映射后失配为零。
- 5.00/5.10 Å 给出约 1.98019802% 对称长度失配；不得误写成 2%。
- 交换端元后对称长度指标不变。
- 原胞/常规胞或等价超胞经过合法映射后结果一致。
- 相同体积但各向异性不同，不得返回零失配。
- 非正交夹角变化能够被角差和完整形变核验识别。
- 不同固定元素占位、映射歧义、参考版本冲突、缺失或 SHA 错误有明确状态。
- 3%/5%/1° 边界及两侧分档正确，缩放副本不能消除真实失配。

### 9.2 衬底功能

- 相同二维晶格主应变为零；刚体旋转主应变也为零。
- 薄膜→衬底等比例 1.02/0.98 时，分别得到 +2%/−2% 工程主应变。
- 非等比例和剪切情况与独立 Gram 矩阵求解一致。
- 双方整数矩阵能重建基矢、面积及晶面关系；等价换基不改变主伸长比。
- 长度容差通过但主应变>3%时，不得误标为备选。
- 面积等于上限或任一侧超限时严格排除；范围内无解与计算失败分开。
- 最小面积与最小应变属于不同解时，代表方案和推荐行仍保持自洽。
- 1%/3% 边界及两侧分类正确，缺弹性张量时弹性能为空。
- 固定测试晶面与原生 SubstrateAnalyzer 做对照；扩大搜索范围后已有有效解保留。

### 9.3 汇总及交付

- 同时存在 seed101/202 时，只为 seed101 创建衬底任务，结果与其结构 SHA 绑定。
- seed101 缺失、无效或版本歧义时，不自动换 seed202，也不填零；显式覆盖后记录真实选择及原因。
- seed202 衬底缺失不使 seed101 任务失败；已有带隙/声子等性质的双构型覆盖规则仍保留。
- 同名 hkl 但晶胞约定不同不能混用；所有方案记录原晶胞来源和整数变换。
- 不同组分、参考版本和搜索范围不会串组；重排输入不影响身份连接。
- 未收敛带隙、缺失声子/能量结果不会变成零值或“通过”。
- 用户不启用新功能时，原软件推荐和输出行为保持兼容。
- 提供一套无需联网、API key、GPU 或外部数据库的微型示例，能从输入跑到最终主表。
- 提供实际运行命令、依赖安装说明、测试结果、输入输出示例和错误说明。

几何测试应使用有明确解析答案的人工结构；真实材料测试用于补充覆盖，不能只依靠“脚本运行未报错”作为正确性证据。

## 12. 怎样形成探测器应用潜力的证据

### 12.1 定义要评价的应用

本版按带间光电探测组织证据，窄带隙候选可用于红外方向的材料预筛。用户应配置目标波段、工作温度、预计膜厚和入光方式；未给出时保留未知，不能擅自假设室温或某一红外窗口。其他探测机制需要单独定义适用指标。

建议功能名称为“探测器材料应用潜力评价”，也可在现有界面中标为“探测器应用性能评估（材料级）”。软件的功能验收与具体材料的科学结论分别记录：软件能够正确计算、追溯和分级，不等于每个被评价材料都通过。

### 12.2 现有六指标能够支撑的结论

| 证据维度 | 当前可用指标 | 可以支持的表述 |
|---|---|---|
| 光谱适配初筛 | 最终合金的有效带隙及目标波段 | 有进入目标光谱范围的带隙基础；实际吸收强度尚需验证 |
| 固溶与结构稳定性 | 端元晶格匹配、合金声子、混合焓、凸包上能 | 在给定方法和筛选阈值下具备继续研究的结构/能量依据 |
| 外延几何适配 | seed101 合金的衬底、晶面、主应变、匹配面积 | 所选代表构型存在低应变衬底几何方案 |

三类证据都齐备且满足设置时，可以推荐为“优先开展探测器方向验证的候选材料”。这六项没有直接计算光电流、暗电流、载流子寿命或噪声，因此不能生成高响应度、高探测率、低暗电流或高速响应的数值结论。

带隙的光子能量尺度可展示为：

\[
\lambda_g\,[\mu\mathrm m]\simeq\frac{1.23984}{E_g\,[\mathrm{eV}]}.
\]

例如 0.40 eV 对应约 3.10 μm。这是带间跃迁的近似能量尺度，输出字段应叫 `gap_equivalent_wavelength_um`，不能自动命名为“已验证探测截止波长”。实际吸收和器件响应还取决于跃迁、膜厚及光路。类似光子能量与带隙关系见 [Hamamatsu 光电二极管技术说明](https://www.hamamatsu.com/content/dam/hamamatsu-photonics/sites/documents/99_SALES_LIBRARY/ssd/si_pd_kspd9001e.pdf)。

只有 E_g>0 且结果有效时计算上述数值；零带隙、负值、未收敛和缺失分别处理，禁止除零或给出无限波长推荐。带隙来源、结构版本和温度近似需要显示。仅有 x=0.5 的合金结果不证明整个组分区间的带隙可调规律。

### 12.3 最有价值的下一步：目标波段吸收谱

若希望加强材料级应用论证，优先补充或导入所选合金构型的吸收系数谱 `alpha(lambda)`，保存波长、吸收系数、偏振/方向、方法、结构 SHA 和收敛性。默认优先与 seed101 对应；不同大小或不同方法的模型必须另列。

外部计算可使用 VASP 等软件得到频率相关介电函数，再推导吸收系数。`LOPTICS` 及其近似、空带和收敛要求见 [VASP 官方文档](https://vasp.at/wiki/index.php/LOPTICS)。本功能只负责规范导入和评价；新增光学计算作为后续独立任务，不在几何命令中自动执行。不同近似、间接跃迁和吸收边展宽等适用范围应写入来源说明。

对明确厚度 d，可提供忽略反射、干涉和散射的单程模型：

\[
A_{\rm single\ pass}(\lambda,d)=1-\exp[-\alpha(\lambda)d].
\]

若 alpha 用 cm⁻¹、d 用 μm，则指数为 `-alpha * d_um * 1e-4`。该值是模型吸收比例，不是外量子效率，也不是响应度。各向异性体系应记录传播/偏振方向，不能无说明用任意平均值代表实际入光。

目标波段和膜厚确定后，再配置 `min_absorptance` 等应用阈值；第一版不设置一个适用于全部材料的统一吸收合格线。吸收数据缺失显示“未计算”，不由带隙猜测数值。

### 12.4 输运、衬底光路与应变后的性质

| 后续证据 | 建议保存 | 结论边界 |
|---|---|---|
| 电子/空穴有效质量 | 数值、方向、拟合窗口、模型和结构身份 | 作为输运相关描述符，不能直接等同于迁移率或寿命 |
| 迁移率、寿命、扩散长度、缺陷信息 | 计算/测量方法、温度、载流子条件和不确定性 | 需要实际数据；不能仅凭能带曲率生成完整输运性能 |
| 衬底光学和器件结构 | 目标波段透过率、厚度、入光侧、接触与绝缘需求 | 背入射时衬底光路尤其需要核验；几何最优衬底不自动等于器件最优 |
| 外延应变后的合金性质 | 选中 match ID、受约束结构、带隙/吸收/稳定性来源 | 体相未应变结果不能直接标成外延薄膜性能；需要后续独立验证 |

第一版可为这些内容预留导入字段，缺失不阻塞几何计算。光学、输运和器件结果不会因为衬底应变较小而自动置为“通过”。

### 12.5 应用证据分级与输出

建议在原推荐旁独立保存下列标记，缺失时保持未完成；不要仅取一个最高等级而掩盖其他缺项：

- `materials_screening_status`：六指标及目标条件的完整性/符合程度，含单 seed 衬底范围。
- `optical_evidence_status`：是否有目标波段的有效吸收证据。
- `transport_evidence_status`：有效质量描述符与实际输运证据分别记录。
- `device_evidence_type`：`not_available`、`modelled` 或 `measured`；模拟与实验不能合并。
- `detector_application_summary`：哪些指标支持应用潜力、哪些尚未验证及建议下一步。

响应度 R、EQE、暗电流、响应时间/带宽、噪声及 D* 属于器件性能证据。导入这些结果时必须保留器件结构、波长、温度、偏压、光功率、面积、测试频率/带宽及方法。D* 不能只凭带隙计算，也不能默认把暗电流对应的散粒噪声当作完整实测噪声；性能比较需要一致的测量条件。[光电探测器评价共识](https://www.nature.com/articles/s41566-025-01759-1)

在几何模式下若没有这些数据，所有器件性能数值列保持空值；仅输出材料潜力和明确缺项。后续器件模拟应标记模型假设，实验结果也只在已测试条件下支持性能结论。

### 12.6 报告中的结论模板及验收

以下是输出模板，方括号必须由实际数据填写，不能作为已得到的结果直接引用：

> 候选 [体系，组分] 在 [方法/阈值] 下具有 [有效带隙与稳定性证据]。选定 seed101 构型在 [衬底及双方晶面] 下存在最大绝对面内主应变为 [数值]% 的几何匹配方案，支持其作为面向 [目标波段] 的光电探测候选材料进一步研究。当前证据为 [材料预筛/光学证据补充/器件模拟/器件测试]；[吸收、输运或器件性能缺项] 尚待验证。衬底结论仅覆盖该代表构型。

增加以下软件验收：

- 目标波段/温度为空时显示未知，不凭空生成特定应用达标结论。
- 0.40 eV 的能量尺度换算约为 3.10 μm；零/无效带隙不会产生无穷或有效截止波长。
- 吸收系数与厚度单位换算正确，模型吸收比例在 0—1 之间，且不被误标为 EQE。
- 没有噪声/器件结果时不生成 D*、响应度或响应时间；模拟与实测标签严格区分。
- 修改代表 seed 时，衬底结构身份和缓存指纹同步变化，原有多构型性质记录仍可追溯。
- 历史双构型共同衬底结果不能直接当作新版本的单 seed 推荐；应按所选结构重新计算或从可核验明细重新汇总。

本文的阈值是初始筛选策略；实际有限温稳定性、界面化学、终止面、可购买切面、应变后的带隙/声子和实验外延成功率不在这两项几何功能的验证范围内。
